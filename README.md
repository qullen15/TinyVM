# TinyVM

Ассемблер и интерпретатор учебной виртуальной машины (УВМ).

## Общее описание

TinyVM — инструмент для учебной виртуальной машины с четырьмя командами.
Ассемблер переводит текст программы на языке ассемблера в машинный код,
интерпретатор исполняет машинный код над моделью памяти.

Текущий статус: завершены этапы 1-3.

## Описание функций и настроек

### Параметры командной строки

| Параметр | Назначение | Обязательность |
| --- | --- | --- |
| `--source PATH` | путь к исходному файлу с текстом программы | обязательный |
| `--output PATH` | путь к двоичному файлу-результату | обязательный |
| `--test-mode` | вывод промежуточного представления | флаг |
| `-h`, `--help` | справка по параметрам | — |

### Язык ассемблера (формат CSV)

Программа — CSV-файл с обязательным заголовком `op,b,c`, далее одна
команда на строку. Колонка `op` — мнемоника (поле A), колонки `b` и `c` —
операнды (поля B и C).

| Мнемоника | Код A | Действие |
| --- | --- | --- |
| `const` | 4 | `mem[B] = C` — загрузка константы |
| `load` | 0 | `mem[C] = mem[mem[B]]` — чтение через указатель |
| `store` | 7 | `mem[mem[C]] = mem[B]` — запись через указатель |
| `popcnt` | 5 | `mem[mem[C]] = popcount(mem[B])` — число единиц |

Диапазоны значений по битовым полям спецификации:
- поле B — 13 бит: 0..8191;
- поле C команды `const` — 29 бит: 0..536870911;
- поле C остальных команд — 13 бит: 0..8191.

Пример программы:

```text
op,b,c
const,312,685
load,778,797
store,249,499
popcnt,333,3
```

### Обработка ошибок

- неверный заголовок CSV;
- неизвестная мнемоника;
- нецелое значение операнда;
- лишние поля в строке;
- значение вне диапазона поля;
- исходный файл не найден;
- отсутствие обязательных параметров — ошибка argparse (код 2).

При ошибке сообщение печатается в stderr, код завершения 1;
при успехе код завершения 0.

### Машинный код (этап 2)

Каждая команда занимает **6 байт** и упаковывается по битовым полям
спецификации (little-endian, младший байт первым):

| Поле | Биты | Ширина |
| --- | --- | --- |
| A (код операции) | 0—2 | 3 |
| B | 3—15 | 13 |
| C (`const`) | 16—44 | 29 |
| C (остальные) | 16—28 | 13 |

Формула упаковки: `value = A | (B << 3) | (C << 16)`, затем
`value.to_bytes(6, "little")`. Неиспользуемые старшие биты — нули.

Ассемблер записывает машинный код в файл, указанный в `--output`,
и печатает его размер в байтах. В режиме `--test-mode` дополнительно
выводятся поля и байты каждой команды в формате спецификации.
Сгенерированные `.bin` не попадают в репозиторий (правило Г2).

### Интерпретатор (этап 3)

Отдельная точка входа `src/interpreter.py` исполняет машинный код.

| Параметр | Назначение | Обязательность |
| --- | --- | --- |
| `--binary PATH` | путь к двоичному файлу с программой | обязательный |
| `--dump PATH` | путь к файлу дампа памяти (XML) | обязательный |
| `--start ADDR` | начальный адрес диапазона дампа | обязательный |
| `--end ADDR` | конечный адрес диапазона дампа | обязательный |

Модель памяти: **память команд и память данных разделены**. Байты
программы доступны только для чтения, память данных — список из 8192
ячеек (по ширине поля B), доступный для чтения и записи.

Основной цикл: чтение 6 байт → декодирование в поля → выполнение.
Реализованы команды `const`, `load`, `store`; `popcnt` добавляется
на этапе 4.

Формат дампа — XML:

```xml
<memory start="200" end="202">
  <cell address="200">11</cell>
  <cell address="201">22</cell>
  <cell address="202">33</cell>
</memory>
```

Ошибки интерпретатора: файл программы не найден, некорректный диапазон
адресов, неверный размер команды, неизвестный код операции, адрес вне
памяти, нереализованная команда. Код завершения 1.

## Сборка и запуск тестов

Сборка не требуется: проект написан на Python и запускается без компиляции.
Внешние зависимости: pytest (для тестов).

Запуск (из корня репозитория):

- Linux / macOS: `./run.sh` или `python3 src/main.py`
- Windows: `run.bat` или `py src/main.py`

Запуск тестов:

- Linux / macOS: `python3 -m pytest tests/ -v`
- Windows: `py -m pytest tests/ -v`

- Демонстрация ассемблера и ошибок (Windows): `./check_asm.bat`
- Демонстрация машинного кода (Windows): `./check_code.bat`
- Демонстрация интерпретатора (Windows): `./check_vm.bat`

## Примеры использования

Обычный режим:

```text
$ py src/main.py --source programs/spec.csv --output out/spec.bin
Размер двоичного файла: 24 байт
```

Ошибка:

```text
$ py src/main.py --source programs/bad_op.csv --output out/x.bin --test-mode
Ошибка: строка 2: неизвестная команда: jump
```

Машинный код (тест-режим):

```text
$ py src/main.py --source programs/spec.csv --output out/spec.bin --test-mode
A=4, B=312, C=685: 0xC4, 0x09, 0xAD, 0x02, 0x00, 0x00
A=0, B=778, C=797: 0x50, 0x18, 0x1D, 0x03, 0x00, 0x00
A=7, B=249, C=499: 0xCF, 0x07, 0xF3, 0x01, 0x00, 0x00
A=5, B=333, C=3: 0x6D, 0x0A, 0x03, 0x00, 0x00, 0x00
Размер двоичного файла: 24 байт
```

Копирование массива через указатели:

```text
$ py src/main.py --source programs/copy.csv --output out/copy.bin
Размер двоичного файла: 90 байт

$ py src/interpreter.py --binary out/copy.bin --dump out/copy.xml --start 200 --end 202
Выполнено команд: 15
Дамп памяти сохранён: out/copy.xml
```
