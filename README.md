# TinyVM

Ассемблер и интерпретатор учебной виртуальной машины (УВМ).

## Общее описание

TinyVM — инструмент для учебной виртуальной машины с четырьмя командами.
Ассемблер переводит текст программы на языке ассемблера в машинный код,
интерпретатор исполняет машинный код над моделью памяти.

Текущий статус: завершён этап 1 (перевод программы в промежуточное
представление).

## Описание функций и настроек

### Параметры командной строки

| Параметр | Назначение | Обязательность |
| --- | --- | --- |
| `--source PATH` | путь к исходному файлу с текстом программы | обязательный |
| `--output PATH` | путь к двоичному файлу-результату | обязательный |
| `--test-mode` | вывод промежуточного представления | флаг |
| `-h`, `--help` | справка по параметрам | — |

### Язык ассемблера (формат CSV)

Программа — CSV-файл с обязательным заголовком `op,b,c`, далее одна
команда на строку. Колонка `op` — мнемоника (поле A), колонки `b` и `c` —
операнды (поля B и C).

| Мнемоника | Код A | Действие |
| --- | --- | --- |
| `const` | 4 | `mem[B] = C` — загрузка константы |
| `load` | 0 | `mem[C] = mem[mem[B]]` — чтение через указатель |
| `store` | 7 | `mem[mem[C]] = mem[B]` — запись через указатель |
| `popcnt` | 5 | `mem[mem[C]] = popcount(mem[B])` — число единиц |

Диапазоны значений по битовым полям спецификации:
- поле B — 13 бит: 0..8191;
- поле C команды `const` — 29 бит: 0..536870911;
- поле C остальных команд — 13 бит: 0..8191.

Пример программы:

```text
op,b,c
const,312,685
load,778,797
store,249,499
popcnt,333,3
```

### Обработка ошибок

- неверный заголовок CSV;
- неизвестная мнемоника;
- нецелое значение операнда;
- лишние поля в строке;
- значение вне диапазона поля;
- исходный файл не найден;
- отсутствие обязательных параметров — ошибка argparse (код 2).

При ошибке сообщение печатается в stderr, код завершения 1;
при успехе код завершения 0.

## Сборка и запуск тестов

Сборка не требуется: проект написан на Python и запускается без компиляции.
Внешние зависимости: pytest (для тестов).

Запуск (из корня репозитория):

- Linux / macOS: `./run.sh` или `python3 src/main.py`
- Windows: `run.bat` или `py src/main.py`

Запуск тестов:

- Linux / macOS: `python3 -m pytest tests/ -v`
- Windows: `py -m pytest tests/ -v`

Демонстрация ассемблера и ошибок (Windows): `./check_asm.bat`

## Примеры использования

Тест-режим (поля как в спецификации УВМ):

```text
$ py src/main.py --source programs/spec.csv --output out/spec.bin --test-mode
A=4, B=312, C=685
A=0, B=778, C=797
A=7, B=249, C=499
A=5, B=333, C=3
```

Обычный режим:

```text
$ py src/main.py --source programs/spec.csv --output out/spec.bin
Разобрано команд: 4
```

Ошибка:

```text
$ py src/main.py --source programs/bad_op.csv --output out/x.bin --test-mode
Ошибка: строка 2: неизвестная команда: jump
```
